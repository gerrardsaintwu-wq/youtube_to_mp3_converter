# Youtube to MP3/MP4 Converter

Enter the URL of the YouTube video or playlist you want to convert, and the application will extract the media and provide it as a downloadable MP3 or MP4 file.

## Usage

1. Start the application locally or visit the deployment.
2. Paste the URL of the YouTube video or playlist you want to convert.
3. Select your desired format (MP3/MP4).
4. Click on the "Search" button.
5. If it's a playlist, select the videos you want and click "Download Selected".
6. Enjoy your favorite content offline!

## Installation

Ensure you have Node.js installed, then run:
```bash
npm install
npm run dev
```
or 
run main.py
